# 📰 CSC 3600 Project - Fake News Detection System Using Machine Learning

This project focuses on combating the spread of misinformation by developing an automated Fake News Detection System using advanced machine learning techniques. With the rapid rise of online content, distinguishing between factual and fabricated information has become a major challenge in the digital age.

The system was trained on a large labeled dataset of real and fake news articles collected from public repositories such as Kaggle. Through a structured pipeline of data acquisition, preprocessing, model training, and evaluation, the project implemented multiple algorithms — including Logistic Regression, Support Vector Machine (SVM), and Neural Networks — to classify news articles with high accuracy.

Users can upload text or URLs for real-time analysis, and the system outputs a confidence score indicating the likelihood of the content being fake. Model performance was evaluated using accuracy, precision, recall, and F1-score, confirming the system’s reliability in identifying misinformation.

Overall, this project demonstrates how AI and natural language processing (NLP) can be applied to promote responsible information sharing and enhance public trust in digital media.
